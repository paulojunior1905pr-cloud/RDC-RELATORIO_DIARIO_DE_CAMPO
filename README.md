# RDC · Relatório Diário de Campo

Painel interativo do RDC do contrato de tanques na RNEST (QWS Serviços).

Acesse pelo GitHub Pages: https://paulojunior1905pr-cloud.github.io/rdc-relatorio_diario_de_campo/

O painel mostra o resumo do último dia, horas-homem aguardando liberação, espera média por TQ, motivos de atraso, efetivo por função, lançamentos por disciplina e a lista de atividades, com filtros por período, TQ, turno e disciplina.

Os dados são agregados a partir do formulário RDC, sem nomes, matrículas ou e-mails.
